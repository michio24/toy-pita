# トイ・ピタ

おもちゃの部品を配置して、連鎖するからくり装置を作るブラウザーゲームです。
ビー玉を転がす、ドミノを倒す、風船を割るなどの仕掛けを組み合わせ、ステージごとのゴールを目指します。

## 起動方法

`index.html` をブラウザーで開くと遊べます。ビルドやパッケージのインストールは不要です。
WebGL を利用できるブラウザーと、外部ライブラリ・フォントを読み込むためのインターネット接続が必要です。

ローカル HTTP サーバーで開く場合は、Python がインストールされた環境で、リポジトリのルートから次を実行します。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで <http://localhost:8000/> を開きます。サーバーの停止は `Ctrl+C` です。

## 遊び方

1. 画面上部でステージのゴールと、使える部品を確認します。
2. 画面下の部品トレイから、部品をドラッグしてステージに置きます。
3. 配置した部品を選択し、位置・角度・向きを調整します。
4. スタートボタンで装置を動かします。
5. ゴールに届かなければリセットして配置を調整します。直前のビー玉の軌跡が調整の手がかりになります。

マウスとタッチ操作に対応しています。スマートフォンでは横向きにするとステージを広く表示できます。
鉄琴はビー玉などが当たると音が鳴ります。音の高さ（ド・レ・ミ・ソ・ラ・高ド・高レ・高ミ）は選択バーの「♪」ボタンで変えられ、続けて置くと 1 音ずつ上がります。
太鼓は当たると「ドン」と鳴り、物を弾ませます。笛は扇風機の風が届いている間だけ鳴り、扇風機との間を動く物がふさぐと止まります。
扇風機は、オフのときに玉（ビー玉・スーパーボール・鉄球・大砲の弾）が勢いよく当たるとスイッチが入ります。サンドボックスでは、回転ハンマーの頭で叩いてもオンになります。一度オンになると、実行中にオフには戻りません。最初のオン / オフは選択バーで設定でき、台のランプ（緑＝オン、赤＝オフ）で確認できます。
あらかじめ置かれた固定部品は動かせません。回転・反転ができるかどうかは部品によって異なります。

### キーボード操作

| キー | 操作 |
| --- | --- |
| `Q` / `E` | 選択した部品を左 / 右に回転（15°刻み、一部の部品は角度制限あり） |
| `F` | 選択した部品の向きを反転 |
| `N` / `Shift+N` | 選択した鉄琴の音を 1 つ上げる / 下げる |
| `O` | 選択した扇風機の、最初のスイッチのオン / オフを切り替え |
| `Delete` / `Backspace` | 選択した部品をトレイに戻す |
| `Space` | 実行 / リセット |
| `Escape` | 選択を解除、またはリプレイを終了 |

### ヒントと再生

- **ヒント**：電球ボタンで説明を表示します。配置中にもう一度押すと、解答例の置き場所を青い影で順番に表示します。
- **早送り**：実行中の速度を 1 倍 / 2 倍に切り替えます。
- **リプレイ**：実行を見返せます。クリア後は自動でリプレイが始まり、見どころをスローで再生します。
- **片付け**：配置した部品をすべてトレイに戻します。

## ステージと評価

15 ステージ（うち 5 つは上級）と、全 27 種類の部品を個数制限なしで使えるサンドボックスがあります。
右上のステージ選択ボタンから切り替えられます。

### サンドボックス専用のからくり

新しい部品を選択すると使い方が表示されます。マウスではトレイの部品にカーソルを合わせても説明を確認できます。

| 部品 | 遊び方 |
| --- | --- |
| カタカタ分岐器 | 上から入った玉を左右交互に送り出します。反転すると最初に送る方向が変わります。 |
| バケツリフト | 最初は左のバケツが上、右が下。重い方が下がり、反対側が上がります。持ち上げたバケツが上端に着くと外側の扉が開き、中の玉や積み木を横へ送り出します（左は左へ、右は右へ）。出口に板やベルを置いて次の連鎖につなげましょう。 |
| 水車・羽根車 | 玉が羽根に当たると回ります。扇風機の風を上半分に当てても回り、羽根で別の玉を押せます。 |
| 回転ハンマー | 赤いスイッチに玉や積み木が当たると、一度だけ回転します。頭で扇風機を叩くとオンになり、大砲を叩くと導火線に点火して一発発射します。反転で打つ方向を変えられます。 |
| シャボン玉メーカー | 上の輪っかへ扇風機の風を当てると泡を出します。泡は風で漂い、物に触れるか約6秒経つと割れます。 |

木目のフレーム、真鍮の滑車、透明なバケツの前面、虹色のシャボン玉など、それぞれの仕組みが見える造形です。
可動部とシャボン玉はリプレイにも記録されます。シャボン玉はメーカー1台につき同時に最大12個で、リセットすると消えます。

| ステージ | 名前 | ゴール |
| --- | --- | --- |
| 1 | ころがれビー玉 | ビー玉でベルを鳴らす |
| 2 | ぴょーんとバネ | ビー玉を高い棚のベルまで届ける |
| 3 | ドミノでドン | ゴールのビー玉をカゴに落とす |
| 4 | カーブでびゅん | 落ちてくるビー玉で、壁の向こうのベルを鳴らす |
| 5 | ふわふわ風船 | 天井の風船を画鋲で割る |
| 6 | てこでカーン | シーソーでビー玉を跳ね上げてベルを鳴らす |
| 7 | 振り子でコツン | 棚のビー玉をカゴに入れる |
| 8 | 大砲ドーン | 大砲の弾で、塔の上のベルを鳴らす |
| 9 | コンベア工場 | 積み木を 3 つともおもちゃ箱に入れる |
| 10 | トイピタ大作戦 | 風船を割り、ベルも鳴らす |
| 11 | スイッチ・オン（上級） | 扇風機のスイッチを入れて、風船を割り、笛も鳴らす |
| 12 | ドレミの階段（上級） | 鉄琴で「ド・ミ・ソ・高ド」を順に鳴らし、ベルも鳴らす |
| 13 | 風の配達（上級） | 大砲で扇風機のスイッチを入れ、ビー玉を 2 つともおもちゃ箱に入れる |
| 14 | ダブルバルーン（上級） | 風船を 2 つとも割り、ベルも鳴らす |
| 15 | トイピタ・フィナーレ（上級） | 「ソ・ミ・ド」を鳴らし、笛を吹かせて、ベルも鳴らす |

上級ステージには、笛を鳴らす・鉄琴でメロディを鳴らすといったゴールがあります。
メロディは指定の音を順番どおりに鳴らすと達成します（同じ音が続けて鳴った分は 1 回と数え、途中で別の音が鳴ると最初からやり直しです）。

通常ステージでは、次の条件で最大 3 つの星を獲得できます。

- ゴールを達成する。
- 配置した部品を、ステージごとの指定個数以内に収める。
- ステージ内のスターを取る。

### ドパモード

右上の「ドパ」をオンにすると、スコアとコイン・虹色の演出が加わります。
連鎖に応じてスコア倍率が上がり、8 連鎖以上で `FEVER!!` が発動して獲得点がさらに 2 倍になります。
ステージごとのハイスコアも記録されます。

## 画質・音・保存

画質ボタンで「最高 → 標準 → 軽量」を切り替えられます。動作が重い場合は軽量を選んでください。
配置中に描画が遅い状態が続くと、画質は自動で一段階下がります。音はスピーカーボタンで切り替えられます。

以下のデータはブラウザーの `localStorage` に保存されます。

- ステージごとの最高評価（星の数）
- 画質設定
- ドパモードのオン / オフと、ステージごとのハイスコア

部品の配置はページを開いている間だけ保持され、再読み込みすると失われます。
保存データはブラウザーやアクセス先ごとに分かれ、ブラウザーのサイトデータを削除すると消えます。

## ファイル構成と技術

```text
toy-pita/
├── index.html  # 画面、スタイル、ゲームロジック、ステージ定義
└── readme.md   # このドキュメント
```

HTML / CSS / JavaScript を `index.html` にまとめています。
3D 描画には Three.js `0.149.0`、物理演算には Planck.js `1.0.0` を使用し、どちらも jsDelivr から読み込みます。
フォントは Google Fonts の「Dela Gothic One」「M PLUS Rounded 1c」、効果音は Web Audio API を使用しています。

画面やゲームの変更は `index.html` で行います。部品定義は `PARTS`、ステージ定義は `LEVELS` にあります。
ビルド・テスト・lint の設定はありません。変更後はブラウザーで起動し、部品の配置、実行、リセット、ステージ切り替えを確認してください。
